# 🗣️ Philosophy & Reasons for Switching

<aside>
💡

**PewDiePie's 4 Reasons for leaving Windows:**

</aside>

### Reason 1 — "Windows talks to me like I'm a baby"

- Constant confirmation pop-ups for non-destructive actions (changing default browser, search engine, deleting files — "Are you super duper sure?")
- Constant update reminders interrupting workflow
- Candy Crush pre-installed and pushed on users
- Bing pushed constantly
- Says: "My first aha moment when I installed Linux was — wait a minute, it does exactly what I wanted to do. Imagine your computer isn't trying to work against you."
- Linux "puts a gun in your hand and says, don't shoot yourself" — gives you real control

### Reason 2 — "The bloat is real" (Minimalism)

- Describes himself as an "epic minimalist"
- Every new Windows install = spending an hour uninstalling pre-packaged bloatware
- Gets worse with every new Windows version
- You pay $100+ for Windows and STILL get ads
- Microsoft makes money from: ads, bloatware subscriptions, and data collection ("stealing your data")
- Microsoft knows most people don't pay for/activate Windows, so they monetize through bloatware and data instead
- Specifically mocks the Windows 11 taskbar — "How many ads? What is this?" — comparing it unfavorably to the clean Windows 7 Start Menu
- Chris Titus Tech's **WinUtil** mentioned as a tool to strip Windows bloat (but notes "the annoyances are not going to stop because it's Windows")

### Reason 3 — Customization ("Linux can change reality itself")

- On Windows: "you can maybe change your wallpaper" and some colors — "Whoopde-doo"
- Notes that Windows technically has alternative shells but they're dead/undocumented, and according to Wikipedia only 2 are active
- On Linux: "you can swap out your GUI entirely. You don't even have to use one."
- "You can cut off the head of Linux and it'll still be like, 'Hey, I'm here. What's up?'"
- Customizing on Linux is called **"ricing"** — and he got "way too into it"
- Says every Linux user should go through the ricing phase — "if you just go on to Gnome or KDE and use it out of the box, you lose out on a lot of that early fun, that early discovery"

### Reason 4 — Gaming on Linux is finally real

- Tried Linux ~15 years ago, uninstalled after a couple days because gaming wasn't possible
- Now: "Gaming on Linux is real at last"
- Credits **Valve** (Gabe Newell / "GabeN") — "Valve came in like Gandalf in Helm's Deep riding a Steam Deck with Proton"
- Valve's motivation: During Windows 8 era, Microsoft introduced the Windows Store. Valve feared Microsoft would lock down PC gaming like mobile app stores (threatening Steam's revenue)
- Valve built on existing open-source work like **Wine**, improved driver support, created **Proton**
- "This is a perfect example of how Linux benefits everyone" — Valve benefits, consumers benefit, ecosystem grows
- Calls it proof that "so many things can be better if people just weren't so greedy"
- Caveat: Gaming still "not perfect" — **anti-cheat** heavy games often don't work on Linux, some older games have issues with cutscene codecs (but usually have documented workarounds)

### Bigger Picture Philosophy

- "I have been tortured by Windows. But now, alas, I am finally free. I escaped the Windows cave. I saw the sun."
- Uses Plato's Cave allegory — he was in the "Windows cave" and now speaks to those still inside
- "Linux is not a product. It's a platform."
- Linux already runs: **NASA**, **SpaceX**, all supercomputers, TVs, smart fridges, Android phones — "It's all Linux, baby"
- References **Linus Torvalds** creating the Linux kernel in the '90s as a hobby project
- "Open source is always the best source" (said semi-jokingly but with conviction)
- Calls on viewers directly: "I need you to install Linux"
- Suggests trying dual-booting or using Linux on a secondary machine to start

# 🛠️ Software & Applications

### Replacing Adobe Photoshop → GIMP

- Used Photoshop for 15 years — all shortcuts and workflow "baked into his brain"
- Describes the sacrifice of leaving Photoshop as the hardest part of switching
- Adobe's cancellation experience: crawling through pages to find unsubscribe button, then hit with an **unsubscription fee** (~$65) for breaking yearly contract — "I have to pay to NOT use your software?"
- This made him resolve to never go back: "Okay, it's over. I'm never going back."
- Switched to **GIMP** as the open-source alternative

### PhotoGIMP (GIMP enhancement)

- Downloaded a Photoshop **icon pack** for GIMP to make it look more familiar
- Downloaded a **keyboard shortcut** mapping that matches Photoshop shortcuts
- Recommends the **PhotoGIMP** project (by Diolinux) — rearranges GIMP's UI to look more Photoshop-like
- Says it's "not perfect, doesn't make it become Photoshop, but it might make it feel somewhat more comfortable"
- Overall verdict: "A worthy sacrifice. It genuinely feels good that I was able to move on."

### Photopea (mentioned)

- Mentioned as another alternative to Photoshop (web-based)
- Referenced in the video around the discussion of Photoshop replacements

### Firefox (Browser)

- Uses Firefox on Linux
- Was unhappy with Firefox taking **2 whole seconds** to open
- Figured out how to optimize Firefox startup time (didn't fully explain how in the video — left viewers wondering)
- Used **Firefox tweaks** from the Arch Wiki (referenced by reaction videos)
- Arch Wiki page: `Firefox/Tweaks`

### Neofetch / Fastfetch (System info display)

- Shows system specs in terminal with ASCII art
- Created a **custom animated ASCII art** for his neofetch — took significant effort
- Called the ASCII art "ashy" (his pronunciation of ASCII)
- Had separate custom ASCII art on both his Mint and Arch setups
- This was one of the most impressive technical feats noted by Linux community reviewers

### Steam / Proton (Gaming)

- **Steam** as the gaming platform on Linux
- **Proton** (by Valve) — compatibility layer that lets Windows games run on Linux
- **Wine** — the open-source foundation Proton builds on
- **Steam Deck** — Valve's handheld that runs Linux, key driver of Linux gaming improvements

# 🎨 Ricing & Customization Tools (Arch Laptop Setup)

<aside>
🔥

PewDiePie's Arch rice was described by Linux community members as going "so much further than most people" — a programmer blogger admitted PewDiePie had "out-Linuxed" him despite not being a programmer.

</aside>

### Hyprland (Tiling Window Manager)

- Uses **Hyprland** instead of a traditional desktop environment (like GNOME or KDE)
- Tiling window manager for **Wayland**
- Uses keyboard shortcuts to switch between workspaces
- The Hyprland developer was reportedly "very excited" that PewDiePie mentioned it

### Waybar (Status bar)

- Custom status bar / taskbar for his Hyprland setup
- Part of his nuclear reactor themed rice

### EWW (ElKowar's Wacky Widgets)

- Custom widget system written in a **Lisp-like** language (Rust-based tool)
- Used to create custom desktop widgets
- GitHub: `elkowar/eww`

### Rofi (Application Launcher)

- Uses **Rofi** as his application launcher instead of a traditional start menu
- Launched via keyboard shortcut

### Custom Daemon (Taskbar auto-hide)

- Wrote a **custom daemon** that automatically shows the taskbar when a window is open and hides it when the desktop is visible
- Had **systemd** manage this daemon — impressed Linux community members who had never bothered doing this themselves

### Nuclear Reactor Theme

- Entire desktop riced to look like a **nuclear reactor control dashboard**
- Nuclear reactor wallpaper — "LARPing as a nuclear power plant engineer"
- ASCII art-inspired aesthetic throughout
- Volume indicator on taskbar turns **red** when high, so it looks like it's gone "critical"
- Everything custom: wallpaper, icons, taskbar, widgets, terminal, cursor

### Zsh (Shell)

- Uses **Zsh** instead of the default **Bash** shell for his terminal

# ⚠️ What He Doesn't Recommend / Sacrifices & Caveats

<aside>
🚫

**"Everything good comes with a sacrifice"** — PewDiePie acknowledges Linux isn't perfect

</aside>

### Adobe Software

- Adobe Creative Cloud apps **do not run on Linux**
- Some older versions can be made to work via Wine/compatibility layers but it's inconsistent
- Adobe charges an **unsubscription fee** if you cancel mid-contract (~$65)
- Calls Adobe "a garbage company"

### Anti-Cheat Games

- Games with heavy anti-cheat (kernel-level) **often don't work** on Linux
- This is a known limitation he acknowledges

### Older Games / Codecs

- Some older games have issues with cutscene video codecs on Linux
- Usually have documented workarounds

### Windows-only Applications

- Acknowledges you might have to give up certain apps that only run on Windows/macOS
- Suggests finding alternatives or making sacrifices
- Values comfort and familiarity of known tools — notes the transition isn't frictionless

### "Linux is not perfect"

- Explicitly states this in the video
- But argues what you gain (freedom, control, customization, no bloat, no ads, no data harvesting) far outweighs what you lose
